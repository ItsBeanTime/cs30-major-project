# What advice would you give to yourself if you were to start a project like this again?
This time, our project took longer than expected that we found ourselves stuck trying to add new attacks and monsters into the game.
We only got the basic code of them game that makes the game work. We were missing the different Easter eggs attacks and alot of the nice to have things in our game.
So we would tell our future selves "Manage time better and find a goal that is easy to achieve within a certain timeframe."


# Did you complete everything in your “needs to have” list?
No, and yes, we didnt plan things well enough to add puzzels in the game, all we had was a single switch. A crutial character of undertale is Toriel who leads the player through the ruins, was unfortunately removed from our game since it would've taken much more time and could possibly take double the time it took us to make this game so far. Also the item system was a bit rushed and could have been fleshed out more along with other things. But technically we had all of our needs to have done.

# What was the hardest part of the project?
The hardest part of the project was probably the dialogue system and the wall / trigger system. These took many hours and a lot of research to complete. The dialogue system still has a lot of bugs, the keyPressed function was very messy and hard to keep track of. I wish we used more comments to help keep ourselves organized because with how much code we have that was one of our biggest challenges.


# Were there any problems you could not solve?
The item system doesn't work completely how we intended but its still "functional". Also I really wanted to add a save system but with the time constraints and all the other stuff I had to complete I just couldn't get around to figuring it out.
